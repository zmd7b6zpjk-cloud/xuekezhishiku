# 收件箱 · 把笔记丢进来

这是知识库的**投递口**。把 `.md` 或 `.txt` 文件放进这个文件夹，然后在网页侧栏点「导入收件箱」，或者运行：

```powershell
python kb.py ingest
```

导入完成后，原文件会被移到 `data/ingested/` 归档，不会丢。

## 文件名与格式

- 有 YAML frontmatter 时，使用其中的 `title`、`discipline`、`tags`：

```markdown
---
title: 固定化酶与传质
discipline: 生物工程
tags: [酶动力学, 传质]
---

正文……
```

- 没有 frontmatter 时：优先取正文第一个 `# 标题`，否则用文件名。
- 文件名开头的日期会被自动去掉，例如 `2026-10-01-酶与载体.md` → 「酶与载体」。
- 正文里的 `#标签` 会自动并入卡片标签。
- 同名卡片已存在时，新卡片会自动加「（2）」后缀，不会覆盖。

## 什么适合放进收件箱

- 上课记的 Markdown 笔记；
- 从其他软件导出的纯文本；
- 一次性的灵感草稿（之后再在网页里整理成正式卡片）。
