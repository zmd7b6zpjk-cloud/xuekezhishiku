化工项目最终要回答一个问题：这个流程值不值得建？

**成本结构**
CAPEX（设备、安装、土建）+ OPEX（原料、公用工程、催化剂、人工、维修）。估算精度：数量级 ±30%、概算 ±20%、详细 ±10%。6/10 法则 $C_2 = C_1 (S_2/S_1)^{0.6}$ 用于设备费用快速估算。

**评价指标**
$$NPV = \sum_{t=1}^{n}\frac{CF_t}{(1+i)^t} - I_0$$
NPV > 0 可行；IRR 是 NPV = 0 的折现率；回收期看现金流平衡点。三者排序可能冲突，决策时以 NPV 为主，辅以风险与战略考量。

**跨学科联络**
现金流里的原料与产品量来自 [[物料衡算与自由度分析]]；能耗来自 [[化工热力学：逸度、活度与相平衡]] 与 [[传递现象：三传类比与纳维-斯托克斯方程]]；安全投入与事故损失见 [[化工安全：HAZOP 与风险矩阵]]；环境外部性见 [[生命周期评价与绿色化工]]。

**易错点**
忽略通胀与税率；把沉没成本算进增量现金流；折现率与风险不匹配。
